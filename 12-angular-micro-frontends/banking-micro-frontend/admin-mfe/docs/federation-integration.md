# Native Federation integration

1. Create the Angular app using the root README instructions.
2. Run `ng add @angular-architects/native-federation-v4`.
3. Select Remote, remote name `admin`, port `4204`.
4. Keep the generated `federation.config.js`, `main.ts` adjustments, and remote entry files.
5. Start the remote on port `4204`.
6. Add the generated remote entry URL and exposed module to the shell's federation manifest according to the CLI-generated configuration.
7. Test the remote standalone first, then test it through the host.

Native Federation configuration differs by package and CLI version. Treat the files generated by your installed package as authoritative.
