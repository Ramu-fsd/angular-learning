# Native Federation integration

## Initialize the remote

For Angular 20/21:

```bash
ng add @angular-architects/native-federation-v4
```

Select remote, name it `payments`, and use port `4202`. Keep generated configuration files and inspect the exposed module identifier and remote entry filename.

## Register in Banking Shell

In Project 1's dynamic host configuration, add the Payments remote using the exact URL and entry filename generated by the schematic. Add a shell route that loads the remote using the helper/API generated for the installed Native Federation version.

Do not copy hardcoded Webpack Module Federation configuration from older tutorials.

## Local run order

Terminal 1 – Payments remote:

```bash
ng serve --port 4202
```

Terminal 2 – Banking Shell:

```bash
ng serve --port 4200
```

If a port is busy, choose another free port and update the host remote URL.
