# Federation integration with Banking Shell

## 1. Initialize this project as a remote

After creating the Angular workspace and copying the source files:

```bash
ng add @angular-architects/native-federation-v4
```

Select the remote role, remote name `accounts`, and port `4201`. Use the generated configuration and exposed entry/module structure produced by the installed schematic.

## 2. Start the remote

```bash
ng serve --port 4201
```

Confirm the app works standalone before connecting it to the host.

## 3. Register in the host

In the Project 1 Banking Shell, add the actual remote entry URL to the generated dynamic-host manifest/configuration. Use the exact entry filename and exposed module identifier generated by the schematic. The manifest shape and entry file naming can vary by package version and selected options; inspect generated files instead of copying a guessed example.

## 4. Add a host route

Update the shell route to load the Accounts remote using the dynamic loading helper/API generated by the Native Federation schematic. Keep the shell's other navigation routes intact.

## 5. Verify

- Start Accounts remote on port 4201.
- Start Banking Shell on port 4200 (or another free port).
- Navigate to Accounts from the shell.
- Confirm account search and detail navigation work.
- Stop the remote and verify the host shows a controlled remote-load fallback.

## Version note

Angular 20/21 uses `@angular-architects/native-federation-v4`. Follow the matching official documentation:
- https://native-federation.com/docs/v4/angular-adapter/getting-started/
- https://native-federation.com/docs/v4/angular-adapter/
