# Accessibility and internationalization

Accessibility is an NFR, not a final polish task.

Include:
- Semantic HTML and correct heading hierarchy.
- Keyboard-only navigation and visible focus.
- Labels and accessible names for controls.
- Screen-reader announcements for async status changes.
- Sufficient color contrast; do not communicate status by color alone.
- Zoom and responsive reflow.
- Locale-aware dates, numbers, and currencies.
- Time-zone handling for transaction timestamps.
- Translated validation and error messages.

Validate against the applicable WCAG level and the organization's accessibility standard.
