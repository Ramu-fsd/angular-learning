## Business scenario

The Accounts domain team owns account portfolio experiences independently from the banking platform shell. This remote demonstrates account search, account summaries, account details, balances, and recent activity using synthetic data.

## Features

- Account portfolio dashboard with total balance and account counts
- Search by account number, customer, or account type
- Filter by account status and type
- Account detail panel with available and ledger balances
- Recent account activity and transaction history
- Account status and currency indicators
- Standalone Angular components and typed domain models
- Angular Signals for reactive in-memory state

## Technology

- Angular CLI 20.0.3 target
- Angular standalone components and Router
- TypeScript
- Signals and computed state
- CSS

## Create the remote workspace

From the parent folder:

```bash
ng new accounts-mfe --standalone --routing --style=css
```

Replace the generated `src` folder with this package's `src` folder. Copy `README.md` and `docs` into the project root.

Then run:

```bash
npm install
```

## Configure Native Federation

For Angular 20/21, use the v4 bridge package:

```bash
ng add @angular-architects/native-federation-v4
```

Choose **remote** when prompted, use remote name `accounts`, and port `4201`. If prompted for the exposed module, select the standalone/root component option offered by the schematic. Keep the generated federation configuration and review it before continuing.

The generated federation configuration is version-sensitive. Do not replace it with older Webpack `ModuleFederationPlugin` examples.

## Run and build

```bash
ng serve --open --port 4201
```

```bash
ng build
```

## Integration with the Banking Shell

The shell from Project 1 is the dynamic host. Once this remote has been initialized and is running, register its actual remote entry URL in the host's generated federation manifest/configuration, following the format created by the schematic. The host route should load the exposed remote entry/module. Do not guess the remote entry filename; use the file generated by your installed Native Federation version.

This package is independently runnable as a standalone application before federation integration.

## Data note

All account and transaction data is synthetic and held in memory. This is a portfolio demonstration, not a banking system. Do not use real customer or account information.
