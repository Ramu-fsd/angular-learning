# Domain workflows

## Patient administration
1. Search using approved patient identifiers.
2. Open the patient administration profile.
3. Verify identity and access purpose before displaying protected data.
4. Review appointment and encounter references.

## Appointment coordination
1. Select patient and department.
2. Check clinician availability and scheduling constraints on the server.
3. Create appointment and issue confirmation.
4. Track check-in, completion or cancellation.
5. Record changes in an audit trail.

## Revenue cycle
1. Capture charge details from an authorized source.
2. Validate coding and payer requirements.
3. Submit claim to payer.
4. Process acknowledgements, denials and remittance.
5. Reconcile payment and patient responsibility.

The sample UI illustrates navigation and queue state only; it does not perform clinical care, coding validation or payer adjudication.
