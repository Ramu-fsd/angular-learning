# Observability and frontend NFRs

Measure user experience and service behavior together.

| NFR | Example measurement |
|---|---|
| Performance | LCP, INP, CLS, API p95/p99 |
| Availability | Successful critical journey rate |
| Reliability | JS error rate, failed API rate |
| Scalability | Peak concurrent sessions, request rate |
| Security | CSP violations, auth failures, dependency findings |
| Accessibility | Automated checks plus manual assistive-tech testing |
| Maintainability | Bundle budgets, test health, deployment frequency |
| Operability | Correlation ID coverage, actionable telemetry |

Do not define arbitrary targets in isolation. Agree objectives with business, platform, and architecture stakeholders, then measure them in production.
