# Domain workflows

## Shipment execution
1. Book shipment and validate serviceability.
2. Plan route and delivery commitments.
3. Select vehicle and driver based on capacity, location, duty hours and eligibility.
4. Dispatch shipment and capture milestone events.
5. Track transit, hub arrival and delivery.
6. Capture proof of delivery and close the shipment.

## Exception management
1. Detect missed milestone, ETA breach, failed delivery or vehicle incident.
2. Create an exception with severity and owner.
3. Assess customer and network impact.
4. Choose recovery action: reroute, reassign, reschedule or return to origin.
5. Notify stakeholders and retain an audit trail.

The demo provides static sample stops and manual status updates. It does not calculate real routes or ingest live GPS signals.
