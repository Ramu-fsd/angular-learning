# Native Federation integration

1. Create `fraud-risk-mfe` using the root README commands.
2. Run `ng add @angular-architects/native-federation-v4`.
3. Select Remote, remote name `fraud-risk`, port `4205`.
4. Preserve the generated federation configuration and entry files.
5. Run the remote standalone on port `4205`.
6. Add its generated remote entry URL and exposed module to the Banking Shell manifest using the exact names generated by the CLI.
7. Test shell navigation, direct remote access and browser refresh.

Federation entry names and configuration formats can vary across package versions. Use the generated files as the source of truth.
