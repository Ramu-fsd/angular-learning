# Native Federation integration

## Initialize remote

For Angular 20/21:

```bash
ng add @angular-architects/native-federation-v4
```

Choose remote, name it `customers`, and port `4203`. Preserve the generated federation configuration and exposed entry/module names.

## Register in Banking Shell

In Project 1's dynamic host manifest/configuration, register the actual remote entry URL generated by the schematic. Add a host route that loads the exposed remote using the generated Native Federation helper/API.

Do not invent remote entry filenames or use old Webpack-specific snippets.

## Local development

Terminal 1 – customer remote:

```bash
ng serve --port 4203
```

Terminal 2 – banking shell:

```bash
ng serve --port 4200
```

Update the host's remote URL if a different port is selected.
