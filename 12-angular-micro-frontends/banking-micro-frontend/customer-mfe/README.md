## Business scenario

The Customer Management domain team owns customer profiles, relationship summaries, contact information, and service interaction history independently from the banking platform shell. This remote demonstrates a customer relationship workbench with synthetic data.

## Features

- Customer portfolio dashboard and segment metrics
- Search customers by name, customer ID, email, or city
- Filter by customer segment and relationship status
- Customer detail view with profile and contact information
- Relationship summary and linked account references
- Recent service interaction timeline
- Customer risk and KYC review indicators (illustrative only)
- Standalone Angular components, typed models, Signals, and Router

## Technology

- Angular CLI 20.0.3 target
- Angular standalone components
- TypeScript
- Signals and computed state
- Angular Router
- CSS

## Create the remote workspace

```bash
ng new customer-mfe --standalone --routing --style=css
```

Replace the generated `src` folder with this package's `src` folder. Copy `README.md` and `docs` into the project root.

```bash
npm install
```

## Configure Native Federation

For Angular 20/21:

```bash
ng add @angular-architects/native-federation-v4
```

Choose **remote**, use remote name `customers`, and port `4203`. Keep the generated federation configuration. Do not replace it with older Webpack Module Federation configuration.

## Run and build

```bash
ng serve --open --port 4203
```

```bash
ng build
```

## Integration with Banking Shell

The Banking Shell from Project 1 is the dynamic host. Once this remote is initialized, register its actual remote entry URL in the host's generated federation manifest/configuration and expose/load the remote using the identifiers generated by the installed schematic. Inspect generated files; do not guess remote entry filenames or exposed module identifiers.

## Data note

All customer identities, contact information, account references, and service interactions are synthetic. This project is a portfolio demonstration and must not contain real customer data.
