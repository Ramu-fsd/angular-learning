# Security and privacy
- Minimize PII returned to the browser; mask national identifiers.
- Store document binaries in controlled object storage, not browser local storage.
- Use short-lived scoped document access links.
- Encrypt in transit and at rest; manage keys centrally.
- Enforce least privilege and maker-checker approval where policy requires it.
- Audit sensitive record access and analyst decisions.
- Align retention/deletion with approved legal and regulatory policy.
- Never treat a browser checklist or risk label as an authoritative compliance decision.
